# GitHub Pages

This website is designed to be deployed using GitHub Pages.

To deploy:

1. Push the project files to the GitHub repository.
2. Open the repository on GitHub.
3. Go to:

   `Settings → Pages`

4. Select:

   `Deploy from a branch`

5. Select:

   `main`

6. Select:

   `/ (root)`

7. Click **Save**.

GitHub will create a live website URL.
